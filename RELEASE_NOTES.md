CircuitVision for Android and web.

- On-device photography, OpenCV component-region detection, local Tesseract OCR, and resistor-band tools.
- Editable schematics with photo highlighting, manual pin connections, and visible-wire connectivity suggestions.
- Local project saving, project JSON import/export, and SVG export.

Download `CircuitVision.apk` and open it on your Android device. No development tools are needed. Preserve your projects by installing updates over the existing app.

Recognition requires review. Component regions and visible connections are heuristic suggestions; hidden traces and automatic multi-pin connectivity are not supported. See the README for recognition and camera-control limits.
